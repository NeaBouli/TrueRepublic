# TrueRepublic v0.4.0 - Web Client Release

**Complete React-based web client for TrueRepublic blockchain governance and DEX**

## 10-Week Development Journey - COMPLETE!

This release represents **10 weeks of intensive development**, delivering a full-featured web client for the TrueRepublic blockchain. Every week brought a major milestone, building from wallet foundations to a production-ready governance and DEX platform.

## Complete Feature Set

### Wallet & Security
- **Encryption:** AES-GCM 256-bit with PBKDF2 key derivation
- **Mnemonic:** BIP39 standard (24-word)
- **Derivation:** Cosmos path `m/44'/118'/0'/0/0`
- **Storage:** Encrypted localStorage
- **Multi-asset:** PNYX + IBC token support

### Governance
- **Browse:** Domains, issues, suggestions
- **Vote:** Anonymous voting with ZKP proofs
- **Create:** Submit suggestions with PayToPut anti-spam
- **Endorse:** Place stones (systemic consensing)
- **Participate:** Full governance lifecycle

### Decentralized Exchange
- **Swap:** Token swaps with multi-hop routing
- **Liquidity:** Add/remove liquidity to pools
- **Analytics:** Pool stats, APY, volume
- **Positions:** Track LP shares and earned fees

### Membership & Identity
- **Onboarding:** 2-step verification process
- **Invites:** Domain invite links
- **Identity:** Anonymous ZKP identity management
- **Merkle Proofs:** Membership verification

### Administration
- **Domain Stats:** Members, treasury, activity
- **Member Management:** Add/verify members
- **Invites:** Generate and share links
- **Permissions:** Admin-only access control

### Network Monitoring
- **Statistics:** Block height, validator count, chain ID
- **Validators:** PoD consensus validator list
- **Blocks:** Recent blocks with proposers
- **IBC:** Cross-chain connection status

## Quick Start

### Prerequisites
```bash
Node.js 20.19+ or 22.12+
npm or yarn
```

### Installation
```bash
git clone https://github.com/NeaBouli/TrueRepublic.git
cd TrueRepublic/client-web
npm install
```

### Development
```bash
npm run dev
# Opens http://localhost:5173
```

### Production Build
```bash
npm run build
# Output: dist/
```

### Configuration
Edit `src/config/chains.ts` to point to your chain:
```typescript
export const TRUEREPUBLIC_MAINNET: ChainConfig = {
  chainId: 'truerepublic-1',
  rpc: 'https://rpc.truerepublic.io',
  rest: 'https://api.truerepublic.io',
  // ...
};
```

## Known Limitations

### ZKP Implementation
**Current (v0.4.0):** Mock implementation
- SHA-256 hashing (instead of Poseidon/MiMC)
- 2-second proof generation (simulated)
- Placeholder proof structure

**Planned (v0.4.1):** Real gnark-wasm
- Groth16 proof generation (20-30s)
- Poseidon/MiMC hashing
- Real circuit compilation from Go

### Other Limitations
- **Transaction History:** Placeholder only (not implemented)
- **IBC Transfers:** Query support only (no transfer UI yet)
- **Mobile Apps:** Web only (native apps planned for v0.5.0)
