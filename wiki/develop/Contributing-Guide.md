# Contributing Guide

Use the repository's maintained
[CONTRIBUTING.md](https://github.com/NeaBouli/TrueRepublic/blob/main/CONTRIBUTING.md)
for contribution workflow, licensing, review, test, and security requirements.

TrueRepublic is a community-governed open-source project. The maintained guide
records the contributor-retained copyright model, collective attribution,
current licensing terms, provenance boundaries, and inbound contribution
rules.
