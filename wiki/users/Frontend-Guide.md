# Maintained Frontend Guide

The current beta interface is `client-web`. Use these maintained documents:

- [Client README](https://github.com/NeaBouli/TrueRepublic/blob/main/client-web/README.md)
- [Web client guide](https://github.com/NeaBouli/TrueRepublic/blob/main/docs/user-manual/web-wallet-guide.md)

maintained tree. Do not use this recovery build with real keys or funds.
